# Cà Phê Việt — Website tĩnh

## Nội dung
Website gồm 04 trang HTML5:
- `index.html` — Trang chủ
- `about.html` — Về chúng tôi
- `products.html` — Sản phẩm
- `contact.html` — Liên hệ

CSS dùng chung nằm trong `css/style.css`. Hình minh họa nằm trong `images/` và được tự tạo bằng SVG để tránh liên kết hình ảnh bị lỗi.

## Chạy thử
Mở `index.html` bằng trình duyệt. Tất cả liên kết nội bộ dùng đường dẫn tương đối.

## Triển khai GitHub Pages
1. Tạo một repository GitHub mới.
2. Upload toàn bộ nội dung thư mục `project`.
3. Vào **Settings → Pages**.
4. Chọn **Deploy from a branch**, branch `main`, thư mục `/ (root)`.
5. Sau khi triển khai, sao chép địa chỉ GitHub Pages vào file `website-url.txt`.

## Ghi nguồn
- Nội dung và bố cục: tự xây dựng cho bài tập.
- Hình minh họa: tự tạo bằng SVG, không sử dụng ảnh bên ngoài.
- Font giao diện: DM Sans và Playfair Display được tham chiếu từ Google Fonts trong CSS. Nếu cần website hoàn toàn không phụ thuộc Internet, có thể thay bằng font hệ thống.
